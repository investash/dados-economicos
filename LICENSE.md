# Licença dos dados econômicos — ODbL

Os **dados** deste repositório (`dados/`) são redistribuídos sob a
**Open Data Commons Open Database License (ODbL) v1.0**, a mesma licença sob
a qual o Banco Central do Brasil disponibiliza as séries SGS e PTAX em
dadosabertos.bcb.gov.br.

* Texto oficial da licença: <https://opendatacommons.org/licenses/odbl/1-0/>
* Resumo legível: <https://opendatacommons.org/licenses/odbl/1-0/summary/>

## O que isso significa na prática

* Você pode copiar, distribuir e usar a base de dados, inclusive
  comercialmente.
* Derivados e obras coletivas devem ser distribuídos sob a mesma licença
  (share-alike).
* Se você usa o conteúdo em público, deve indicar a fonte (attribution —
  veja `NOTICE.md`).
* Se você usa a base ou uma versão modificada em um serviço público, deve
  oferecer o acesso à base de dados original (share-alike da base).

## Escopos distintos

* `dados/` — dados econômicos: **ODbL 1.0**.
* `scripts/`, `esquemas/` — ferramentas de validação e contratos: **MIT**
  (ver `LICENSE`).
* Documentação em `README.md`, `AGENTS.md`, `docs/`, `NOTICE.md`: texto
  simples para conveniência, sem licença de código aplicável.

Consulte `NOTICE.md` para a atribuição completa ao Banco Central do Brasil e
proveniência das séries.
